# Product Images Directory

Place your product images and assets in this directory:

## Required Images
- `/logo.png` - Your store logo
- `/hero-image.jpg` - The hero section background image
- `/butterflies.png` - Decorative background pattern
- `/payments.png` - Payment methods icons
