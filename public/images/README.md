# Image Directories for Doctor Appointment App

This directory contains placeholder images for the doctor appointment application. Below are instructions on what images to add to each directory:

## Directory Structure

```
public/images/
├── doctors/       # Doctor profile images
├── hero/          # Hero/banner images for homepage
├── about/         # Images for about page
├── icons/         # Icon images
├── patients/      # Patient testimonial images
├── specialties/   # Specialty icon images
├── ui/            # UI element images
```

## Recommended Images

### doctors/
Add doctor profile images named:
- doctor1.jpg
- doctor2.jpg
- doctor3.jpg

### hero/
Add hero banner images named:
- hero-1.jpg
- hero-2.jpg

### Default Avatar
Add a default avatar image named:
- default-avatar.png

## Image Sources

You can get free-to-use images from these sources:
1. [Unsplash](https://unsplash.com/)
2. [Pexels](https://www.pexels.com/)
3. [Pixabay](https://pixabay.com/)

Search for terms like "doctor", "medical", "healthcare", "hospital" to find appropriate images.

## Image Dimensions

- Doctor profile images: 600x800px
- Hero images: 1200x600px
- Default avatar: 200x200px
